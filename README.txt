RALLY CARDS — Cards only, for offline iPad play

This app has all 70 cards, including duplicates, in the original black, red,
blue, gray, and green colors. It works with your physical board and die.
Enter up to 15 player names. Each card displays whose turn it is.
This version does not include a racetrack or scorekeeping.

FEATURES
- Colored card borders are twice as wide, including the top edge.
- Open Player names, enter names one per line, and tap Save players.
- Names follow the entered order and restart with the first player each round.
- Previous also restores the matching player for that card.
- Names stay saved between rounds and when reopening the app.
- Changing names after drawing a card asks to reshuffle the current round.
- Draw one large, easy-to-read card at a time.
- Shuffle all 70 cards for the start of each round.
- Previous reviews or undoes a draw. Drawing again returns to the same card.
- The card count and remaining count update automatically.
- Saved progress survives closing and reopening when device storage is available.
- The round number can continue beyond round 3 if you play another game.

INSTALL ON YOUR IPAD
1. Extract this ZIP on a computer.
2. Upload ALL files into a NEW GitHub repository, or a separate cards-only
   subfolder in your existing repository. Do not replace your full board game.
3. If using a new repository, enable GitHub Pages from main / (root).
4. While connected to Wi-Fi, open the cards page's published address in Safari.
   A subfolder's address ends in /cards-only/ if you named it cards-only.
5. Wait for Ready for offline play.
6. Tap Share > Add to Home Screen (look under More if needed).
7. Enable Open as Web App if shown, then tap Add.
8. Open the new Rally Cards icon while still connected to Wi-Fi and wait for
   Ready for offline play there too.
9. Test closing and reopening it in Airplane Mode.

The first setup requires Wi-Fi and the published HTTPS page. Once installed,
you can open the Home Screen app and draw/shuffle cards offline. Opening the
ZIP or its HTML preview directly in the iPad Files app is not the installation
method. Keep using the Rally Cards Home Screen icon for saved progress.
Clearing website data removes the offline copy and saved progress.
